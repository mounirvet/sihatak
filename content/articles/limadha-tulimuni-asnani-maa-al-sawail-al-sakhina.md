ألم الأسنان عند شرب السوائل الساخنة غالباً علامة حساسية أسنان، تحدث حين تصل الحرارة إلى طبقة العاج الحسّاسة تحت المينا بسبب تآكلها أو انحسار اللثة أو تسوّس أو سنّ متصدّع. فأن تنتظر فنجان قهوتك ثم يلسعك ألم حادّ مع أول رشفة تجربة مزعجة تجعلك تتردّد قبل كل مشروب — والخبر الجيد أن لهذا الألم أسباباً محدّدة قابلة للتشخيص والعلاج.

## ما الذي يحدث داخل السنّ؟

تحت طبقة [المينا](/maqalat/al-mashrubat-al-hamida-wa-bidayat-al-tasawwus/) الصلبة توجد طبقة **العاج** التي تحتوي قنوات دقيقة تصل إلى عصب السنّ. حين تتعرّض هذه الطبقة — لأي سبب — تصل الحرارة (والبرودة والحلو) إلى العصب فتسبّب الألم. هذا جوهر **حساسية الأسنان**.

## الأسباب الشائعة

تتعدّد أسباب وصول الحرارة إلى العاج بين تآكل المينا وانحسار اللثة ومشكلات السنّ، كما يوضّح الجدول:

| السبب | كيف يسبّب الألم |
|---|---|
| تآكل المينا | يكشف العاج تحتها |
| [انحسار اللثة](/maqalat/al-litha-baad-sin-al-arbain-wiqaya/) | يكشف جذور الأسنان الحسّاسة |
| تسوّس | يصل قرب العصب |
| سنّ متصدّع | ينقل الحرارة للداخل |
| حشوة/ترميم قديم | تسرّب حول الترميم |
| بعد علاج سنّي حديث | حساسية مؤقتة |

## متى يكون الألم بسيطاً ومتى يقلق؟

التمييز مهمّ:

- **ألم خفيف عابر** يزول فور إبعاد المشروب → غالباً حساسية بسيطة.
- **ألم حادّ أو مستمرّ أو نابض** يبقى بعد المشروب → قد يشير إلى تسوّس عميق أو **التهاب عصب** يحتاج علاجاً سريعاً.

## تدابير مؤقّتة للتخفيف

- معجون مخصّص **للأسنان الحسّاسة**.
- [تفريش لطيف](/maqalat/al-litha-al-mutahassisa-asbab-wa-rutin/) بفرشاة ناعمة لتجنّب زيادة الانحسار والتآكل.
- تجنّب التنقّل الحادّ بين الساخن جداً والبارد جداً.

لكن هذه تدابير مؤقّتة لا تعالج السبب.

## متى تستشير الطبيب؟

لا تتجاهل الألم المتكرّر مع الساخن. استشر طبيبك ليحدّد السبب الدقيق — حساسية، تآكل، تسوّس، أو التصدّع — ويعالجه. الألم الحادّ أو المستمرّ أو المصحوب بتورّم يستدعي زيارة عاجلة.

## الخلاصة

ألم الأسنان مع السوائل الساخنة غالباً حساسية أسنان، سببها وصول الحرارة إلى العاج تحت المينا بفعل التآكل أو انحسار اللثة أو التسوّس أو التصدّع أو ترميم قديم. الألم العابر قد يكون بسيطاً، أما الحادّ أو المستمرّ أو النابض فقد يعني التهاب عصب يحتاج علاجاً. لا تتجاهل الألم المتكرّر، واستشر طبيبك لتحديد السبب وعلاجه.
